# 바다상인 (Sea Merchant) — 웹 프로토타입

대항해시대풍 3인칭 항해 시뮬레이션의 핵심 루프 프로토타입입니다.
저해상도 Canvas2D 렌더러와 DOM 기반 HUD로 순수 브라우저에서 동작하며, 정적 서버만으로 실행할 수 있습니다.

## 핵심 루프

바다에서 배를 조종 → 항구도시 클릭 시 정박 → 도시 내부에서 캐릭터 조작 → NPC 상호작용/인벤토리 → 다시 출항.
해상에서는 해적선과 조우 시 전투 모드로 전환되어 포격전을 벌일 수 있습니다.

## 실행 방법

```bash
cd web
npm install
npx serve .   # 또는 python3 -m http.server
```

브라우저에서 `index.html`을 서빙하는 주소로 접속 후 화면을 클릭하면 마우스 시점 조작이 시작됩니다.

## 조작법

### 바다
- `W` / `S`: 속도 +1 / -1 (정박 0, 전진 최대 +5, 후진 최대 -3)
- `A` / `D`: 좌/우 선회
- 드래그: 시점 회전(배 진행 방향과는 완전히 분리됨)
- 좌클릭: 정박(항구 근접 시) / 포격(전투 중)
- `Space`: 포격(전투 중)
- `M`: 전체 지도(월드맵) 열기/닫기
- `T`: 탑승 중인 선박 정보 카드 열기/닫기

### 도시
- `W A S D`: 이동 (카메라 기준)
- 드래그: 시점 회전
- 우클릭: 클릭 지점으로 이동
- `F` 또는 좌클릭: 상호작용
- `E`: 인벤토리 토글
- `M`: 전체 지도(월드맵) 열기/닫기
- `T`: 탑승 중인 선박 정보 카드 열기/닫기

### 전체 지도(월드맵)
- `M` 또는 `ESC`: 닫기
- `◀` `▶` (키보드 화살표 또는 화면 버튼): 다른 해역 페이지로 전환
- 대항해시대 게임처럼 지도가 해역별로 나뉘어 있으며, 전 세계 해안선·항구 데이터 위에 랭크와 발견 상태에 따른 잠금 정보를 표시합니다.
- 열람 전용 기능이며 플레이어의 실제 이동/조작과는 무관합니다(연 동안 시뮬레이션이 일시 정지됩니다).

### 선박 정보 카드 (`T`)
- 대항해시대 온라인 함선 도감(모험용/교역용/전투용 3분류, 내구도·적재량·화력·선회·속도 지표)을 참고해 20척 선박에 `role`(모험/교역/전투)을 부여했습니다.
- 역할에 따라 외형도 달라집니다: 모험용 소형선은 삼각돛(라틴세일) 단일 마스트, 교역용선은 넉넉한 선체 폭과 갑판 화물(궤짝·술통), 전투용 대형/초대형선은 2단 포열과 이물 군기 추가.
- `T`로 열리는 카드는 CSS 막대 그래프로 동급 함대 내 최대치 대비 능력치를 시각화합니다. 열람 중에는 월드맵과 마찬가지로 시뮬레이션이 일시 정지됩니다.

## 프로젝트 구조

```
web/
  assets/              타이틀 원화와 공통 해도 텍스처
  docs/                선박 모델 및 UI 비주얼 가이드
  index.html           엔트리와 DOM HUD 스타일
  src/
    data/              선박/도시/해상 NPC/해역/월드맵 리전 데이터
    entities/           선박·캐릭터·해양·포탄 등의 게임 엔티티와 컨트롤러
    render/             Canvas2D 표면, 픽셀 스프라이트, 등각 투영 선박 렌더러
    scenes/             바다 씬 / 도시 씬
    systems/            교역·전투·랭크·도감·저장 등 게임 시스템
    ui/                 HUD와 시장·조선소·의뢰 등 DOM 패널
    state.js            전역 게임 상태
    main.js             부트스트랩 & 게임 루프
  build.mjs             esbuild 번들 빌드 (dist/bundle.js)
  build-artifact.mjs     이미지까지 내장한 단일 HTML 배포 파일 생성
```

## 확장 포인트 (다음 단계)

- `src/data/ships.js` / `cities.js`: 선박·도시 데이터는 스키마가 이미 정의되어 있어 항목만 추가하면 확장됩니다.
- `CityScene`은 데이터 기반 제너릭 생성기라 8개 항구도시 모두 입장 가능합니다. 다만 리스본/세비야 2곳만 도시 고유 NPC 대사가 채워져 있고(`built: true`), 나머지는 기본 NPC로 대체됩니다 — `cities.js`에 `npcs` 배열만 채워주면 바로 고유 콘텐츠가 됩니다.
- 시장 매매, 조선소, 의뢰, 학문·도감, 칭호 시스템은 구현되어 있습니다. 다음 확장에서는 도시별 고유 콘텐츠와 모바일 HUD 밀도를 다듬는 것이 우선입니다.
