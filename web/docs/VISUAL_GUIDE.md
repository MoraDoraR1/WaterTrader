# WaterTrader 비주얼 가이드

## 1. 비주얼 콘셉트

**항해일지 위에 펼쳐지는 대항해시대**를 핵심 방향으로 삼는다. 깊은 대서양의 어둠, 오래된 해도와 황동 항해 도구, 멀리 보이는 항구의 불빛을 한 화면에 결합해 모험과 교역의 낭만을 전달한다.

- 분위기: 차분하고 깊이 있는 해양 모험, 손으로 다듬은 항해일지
- 시대감: 16~18세기 범선과 항구를 연상시키되 박물관식 재현보다 게임 판독성을 우선
- 표현: 저해상도 게임 화면과 어울리는 페인터리 픽셀 아트 질감
- 피해야 할 것: SF 네온, 현대식 유리 패널, 과도한 금색 장식, 실사 사진, 애니메이션 캐릭터 중심 구성

## 2. 컬러 시스템

| 역할 | 색상 | 용도 |
| --- | --- | --- |
| Atlantic 950 | `#041019` | 화면 최심부, 오버레이 |
| Atlantic 900 | `#071A26` | 기본 패널 배경 |
| Atlantic 800 | `#0D2A38` | 보조 패널, 호버 |
| Oxide Teal | `#2E6F75` | 항해 정보, 활성 보조색 |
| Parchment | `#E8D7B0` | 본문과 주요 정보 |
| Brass | `#D6A84B` | 제목, 주요 버튼, 재화 |
| Seafoam | `#77C4B8` | 성공, 순풍, 탐험 정보 |
| Coral | `#D66A57` | 위험, 전투, 부족 상태 |
| Mist | `#9FB5BF` | 부가 설명, 단축키 |

금색은 가치와 주요 행동에만 사용하고, 일반 테두리에는 채도를 낮춘 황동색을 사용한다. 위험 상태는 빨강 단독 대신 아이콘·문구·명도 변화를 함께 적용한다.

## 3. 타이포그래피

- 화면 제목: `Georgia`, `Noto Serif KR`, `Malgun Gothic` 순서의 세리프 계열. 넓은 자간과 얇은 그림자를 사용한다.
- UI 본문: `Malgun Gothic`, `Apple SD Gothic Neo`, `Noto Sans KR`.
- 숫자와 재화: 고정 폭에 가까운 숫자 폭(`font-variant-numeric: tabular-nums`)을 사용한다.
- 최소 크기: 주요 HUD 13px, 보조 정보 11px. 단축키 안내만 10px까지 허용한다.

## 4. 표면과 형태

- 패널: `Atlantic 900` 92~96% 불투명도, 1px 황동 테두리, 12~16px 모서리.
- 패널 안쪽에 얇은 하이라이트와 깊은 외곽 그림자를 더해 종이와 목재 프레임의 층을 만든다.
- 제목 영역과 본문 사이에는 황동색 구분선 또는 낮은 대비의 해도 무늬를 사용한다.
- 버튼: 기본/강조/위험의 3단계. 최소 높이 40px, 키보드 포커스가 분명해야 한다.
- HUD: 모서리에 고정된 정보 덩어리를 3개 이하로 묶고, 게임 세계를 가리는 면적을 최소화한다.

## 5. 레이아웃 우선순위

1. 현재 해역·항구 및 선박 생존 정보
2. 재화·사기·선원과 항해 상태
3. 조작 가능한 주요 행동과 단축키
4. 장식 및 분위기 요소

타이틀 화면은 중앙의 선택 카드에 시선을 모으고, 생성된 항구 이미지는 분위기와 서사를 담당한다. 플레이 화면에서는 모든 HUD의 배경 명도를 통일하고, 서로 다른 테두리와 투명도로 생기는 시각적 잡음을 줄인다.

## 6. 이미지 자산

### `assets/title-harbor-hero.webp`

- 용도: 타이틀 화면 전면 배경
- 구성: 넓은 항구와 출항하는 상선, 낮은 수평선, 중앙 UI 뒤는 충분히 어둡고 단순하게 유지
- 처리: 화면 위에 짙은 남색 그라디언트와 비네트를 겹쳐 텍스트 대비 확보
- 금지: 이미지 내부 텍스트, 로고, UI 프레임, 워터마크

### `assets/panel-nautical-texture.webp`

- 용도: 모달·지도·인벤토리 카드의 저대비 표면 질감
- 구성: 희미한 해안선, 항로, 나침반 장식과 종이 입자
- 처리: 패널 배경색 아래 8~14% 강도로만 사용
- 금지: 읽을 수 있는 지명이나 큰 상징, 강한 대비

## 7. 모션과 접근성

- 호버와 패널 등장 전환은 120~220ms 범위로 제한한다.
- `prefers-reduced-motion`에서는 반복 점멸과 이동 애니메이션을 끈다.
- 본문 텍스트는 배경 대비 4.5:1 이상을 목표로 한다.
- 키보드 포커스는 Brass 외곽선과 2px 간격으로 표시한다.
- 작은 화면에서는 타이틀 카드 폭을 뷰포트에 맞추고 HUD 단축키를 압축한다.

## 8. 적용 체크리스트

- [ ] 타이틀 이미지와 선택 카드가 서로 경쟁하지 않는다.
- [ ] 주요 버튼과 선택 상태를 색상만으로 구분하지 않는다.
- [ ] HUD 텍스트가 바다와 육지 양쪽 배경에서 읽힌다.
- [ ] 공통 패널이 동일한 테두리·그림자·배경 질감을 사용한다.
- [ ] 생성 이미지가 배포용 단일 HTML에도 포함된다.
- [ ] 1280×720과 작은 화면에서 핵심 정보가 잘리지 않는다.
