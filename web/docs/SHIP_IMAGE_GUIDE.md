# WaterTrader 선박 이미지 가이드

## 1. 적용 범위

`src/data/ships.js`의 `SHIPS` 78척을 모두 개별 이미지로 제작한다.

- 구매·건조 가능한 선박: 66척
- 해적·보스·NPC 전용 선박: 12척
- 적용 화면: 조선소의 구매·건조·함대·수리 목록, `T` 선박 정보 카드
- 항해 월드: 기존 Canvas2D 방향별 절차 렌더링을 유지한다. 정적인 카드 이미지를 방향 스프라이트로 재사용하지 않는다.

## 2. 공통 아트 디렉션

**항해 박물관의 선박 도감 판화가 살아 움직이는 듯한 페인터리 픽셀 아트**를 기준으로 한다.

- 시점: 우현 선수 3/4, 배의 이물은 화면 오른쪽을 향한다.
- 구도: 선박 전체가 프레임 안에 들어오며 화면 폭의 약 72~82%를 차지한다.
- 수평선: 상단 30~38%에 두어 돛대와 선체 실루엣을 분리한다.
- 배경: 낮은 파도의 바다와 단순한 대기 원근만 사용한다. 항구·인물·전투 장면은 넣지 않는다.
- 표현: 타이틀 원화와 같은 손으로 칠한 2D 게임 아트, 정교한 16비트 질감, 선명한 실루엣.
- 금지: 이미지 내부 글자·국기 문장·로고·워터마크·UI 프레임·현대 선박·증기기관·사진풍 합성.

## 3. 역할별 분위기

| 역할 | 빛과 바다 | 강조 요소 |
| --- | --- | --- |
| 모험용 | 청록빛 새벽, 맑은 수평선 | 날렵한 선수, 팽팽한 돛, 가벼운 물보라 |
| 교역용 | 온화한 금빛 아침 | 넓은 선복, 화물 해치·갑판, 안정감 있는 흘수 |
| 전투용 | 흐린 청회색 하늘, 산호색 측광 | 포문·장갑·높은 선루, 무거운 선체 |

해적 전용 선박은 검게 바랜 돛과 짙은 적갈색 선체로 구분하되, 해골·문장 같은 작은 도상은 생성 오류를 피하기 위해 사용하지 않는다. 보스와 레전더리는 붉은 측광과 더 강한 파도로 위계만 높인다.

## 4. 선종별 실루엣 규칙

- 캐러벨·다우·제벡: 삼각돛과 날렵한 선수.
- 카락·갈레온·전열함: 높은 선수루·선미루, 다층 포열, 3~4개 돛대.
- 갤리·갈레아스: 길고 낮은 선체, 좌우 노, 이물 집중 무장.
- 스쿠너·클리퍼: 길고 가는 선체, 뒤로 기운 돛대, 큰 종범 또는 다단 사각돛.
- 판옥선·거북선·조운선: 평저형 선체와 조선식 상부 구조.
- 정크·보선: 횡죽이 보이는 부채꼴 정크 돛과 높은 선미.
- 일본·동남아 병선: 얕은 흘수, 노, 누각 또는 방패형 현측 구조.

유명 실존선은 해당 시대의 선체·돛대 수·장식 밀도를 우선하며, 게임 역할 색상은 조명에만 제한적으로 사용한다.

## 5. 파일 규격

- 원본 생성: 이미지 생성 도구의 기본 고해상도 PNG
- 게임 파일: `384 × 256`, WebP, 품질 82
- 경로: `web/assets/ships/<ship-id>.webp`
- 파일명: `SHIPS[].id`와 정확히 일치
- 표시 방식: `object-fit: cover`, 지연 로딩, 역할색 테두리
- 접근성: `alt="<선박 이름> 선박 이미지"`

## 6. UI 적용 규칙

### 조선소

- 데스크톱: 행 왼쪽에 `132 × 88` 썸네일을 배치한다.
- 이미지와 이름·스탯은 하나의 정보 묶음으로 보이게 한다.
- 작은 화면에서는 `96 × 64`로 줄이되 이미지를 숨기지 않는다.
- 이미지 로딩 실패 시 기존 텍스트 행이 무너지지 않도록 이미지 영역만 숨긴다.

### 선박 정보 카드

- 헤더 아래에 `3:2` 비율의 큰 도감 이미지를 배치한다.
- 이미지 하단에 어두운 그라디언트를 겹쳐 국가·등급·시대 정보가 안정적으로 읽히게 한다.
- 이미지 때문에 카드 높이가 화면을 넘지 않도록 본문을 스크롤 영역으로 구성한다.
